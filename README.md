# auditPayments

Expense tracking web app. Tracks who owes you and who you owe.

## Stack
- HTML, CSS, Vanilla JS
- Moment.js for dates

## Features
- Add payee with name, amount, description
- +amount = you receive, -amount = you pay
- Running Give/Take totals
- Search and sort (by name or date)
- Delete entries

## Run
Open `index.html` in a browser. Nothing else needed.

## File Structure
```
index.html - main page
details.html- detail view
script.js   - core logic
extra.js- helpers
rough.js - utilities
moments.js  - date handling
style.css - styles
design.css  - additional styles
detail.js  - detail page logic
```
